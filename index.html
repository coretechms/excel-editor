Test Date Editor

시작 하려면 비밀번호를 입력하세요.

프로그램 관리
비밀번호 관리
1. 기본화면 진입 비밀번호 변경
2. 관리자 모드 비밀번호 변경
3. Firebase 연결
Firebase 연결 대기 중
코드 상단의 firebaseConfig 값을 실제 Firebase 프로젝트 설정값으로 교체해야 연결됩니다.
기본화면 비밀번호 기본값은 1234, 관리자 모드 비밀번호 기본값은 4321입니다.
프로그램 관리
기본화면 진입과 관리자 모드 진입은 서로 다른 비밀번호로 관리됩니다.

엑셀 Test Date 변경 도구

엑셀 파일을 선택한 뒤 원하는 날짜와 시간으로 변경하고 수정 파일을 다운로드합니다.

(주)코아텍 비아이티

1. 엑셀 파일 선택 .xlsx / .xlsm / .xls
원본 파일은 변경하지 않습니다. 권장 형식은 .xlsx 입니다.
보호된 시트는위 비밀번호로 풀고 수정후 같은 비밀번호로 다시 잠급니다 [CINPHOWN].
아직 파일이 선택되지 않았습니다.
2. 날짜 / 시간 입력 변경 기준
시작 분
시작 초
끝 분
끝 초
증가 시간 범위 안에서 랜덤 적용합니다. 예: 6초 ~ 15초
표시 형식은 화면 예시용 입니다.
마지막 항목 시간보다 늦게 저장 할 [ 분 ]
[ 초 ]
3. 변경 방식 대상 선택
4. NO 범위 설정 선택 사항
“특정 NO 범위만 변경”을 선택했을 때만 적용됩니다. 예: 11 ~ 98
5. 미리보기
* Lot Number : - * 최종항목 날짜/시간 : - * Creation Time 변경값 : - 0건
엑셀 파일을 선택하면 Test Date 항목을 자동 분석합니다.
대기 중입니다.
