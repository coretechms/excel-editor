엑셀 Test Date 변경 도구

엑셀 파일을 선택한 뒤, 각 폼 상단의 Test Date: YYYY/MM/DD HH:MM 값을 원하는 날짜와 시간으로 변경하고 수정본을 다운로드합니다.

1. 엑셀 파일 선택 .xlsx
브라우저에서 직접 읽고 수정합니다. 원본 파일은 변경하지 않습니다.
아직 파일이 선택되지 않았습니다.
Firebase 연결 대기 중
2. 날짜 / 시간 입력 변경 기준
분
초
3. 변경 방식 대상 선택
4. NO 범위 설정 선택 사항
“특정 NO 범위만 변경”을 선택했을 때만 적용됩니다. 예: 000002 ~ 000305
5. 미리보기
* 최종항목 날짜/시간 : - 0건
엑셀 파일을 선택하면 Test Date 항목을 자동 분석합니다.
대기 중입니다.
